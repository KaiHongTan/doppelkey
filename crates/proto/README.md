# crates/proto

Wire types for protocol v1 (see `docs/protocol.md`). The Rust crate arrives in Milestone 2; until then this directory holds the shared test vectors.

- `vectors/handles.json`: key inputs and what a shim must recognise. Generated by `compat/test-keeper/gen-vectors.mjs`. Checked against both the Node shim and the test keeper by `compat/node/test/handles.test.mjs`.
